# Changelog

## 1.0.0 — 2026-10-05

First public version of https://kovatec.fi.

- One-page site built from the design handoff of 4 Oct 2026: hero, key figures, what we do, rail expertise with system tiles, references, contact. Matches the design reference at 1440, 1280, 1024, 800, 760, 600, 390 and 360 px.
- Static HTML and CSS only; fonts and images self-hosted; strict Content Security Policy, no scripts.
- Search: title, description, canonical URL, Open Graph image, Organization and WebSite structured data, `robots.txt`, `sitemap.xml`, favicons, 404 page, `security.txt`.
- Hosting: GitHub Pages from `docs/` on `main`, custom domain kovatec.fi with HTTPS enforced (Let's Encrypt certificate for kovatec.fi and www.kovatec.fi).
